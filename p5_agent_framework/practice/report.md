## 当前范围

LangGraph 实践提供完整工作流：加载档案、检索、生成、校验修正、等待确认、幂等保存与读回。已删除功能测试、故障注入、手写 baseline、Agents SDK 对照及其评测数据，现按新增任务恢复 openai-agents 依赖，用于独立 SDK 实践。

## 学到的机制

- 图负责节点调度与暂停恢复，业务规则仍由校验节点负责。
- 校验失败返回生成节点，最多修正两次；缺证据或预算不足时明确结束。
- `interrupt` 等待用户明确确认，`Command` 恢复同一会话。
- 同步检查点让确认状态及请求 ID 在外部写入前落盘；P2 幂等写入覆盖外部写入成功但图尚未更新的重试窗口。
- 模型调用次数单独在请求前持久化，避免超时恢复重置预算；HTTP 使用可取消的异步接口。
